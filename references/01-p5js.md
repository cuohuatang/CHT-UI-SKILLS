# 01 · p5.js 创意编码 — 实战分册

> 开源项目：`processing/p5.js`。JavaScript 创意编程库，擅长图形绘制、动画与鼠标交互。
> 典型产出：活动主视觉、互动海报、数据艺术、粒子背景、教学演示。
> 主入口与全局铁律见 `../SKILL.md`。

## 最小可运行模板（实例模式，首选）

实例模式把 API 挂在 `p` 上，不污染 `window`，可嵌入 React/Vue/任意框架。

```html
<script src="https://cdn.jsdelivr.net/npm/p5@1.11.3/lib/p5.min.js"></script>
<script>
const sketch = (p) => {
  const particles = []
  const COUNT = p.constrain(Math.floor(p.windowWidth * p.windowHeight / 9000), 60, 420)

  class Particle {
    constructor() {
      this.pos = p.createVector(p.random(p.width), p.random(p.height))
      this.vel = p5.Vector.random2D().mult(p.random(0.4, 1.6))
      this.r = p.random(1.5, 4)
    }
    update() {
      const d = p5.Vector.sub(this.pos, p.createVector(p.mouseX, p.mouseY))
      const dist = p.constrain(d.mag(), 1, 200)
      if (dist < 160) this.vel.add(d.setMag(p.map(dist, 0, 160, 1.2, 0))) // 越近推力越大
      this.vel.limit(4); this.pos.add(this.vel)
      if (this.pos.x < -20) this.pos.x = p.width + 20; else if (this.pos.x > p.width + 20) this.pos.x = -20
      if (this.pos.y < -20) this.pos.y = p.height + 20; else if (this.pos.y > p.height + 20) this.pos.y = -20
    }
    draw() { p.noStroke(); p.fill(140, 210, 255, 180); p.circle(this.pos.x, this.pos.y, this.r * 2) }
  }

  p.setup = () => {
    const c = p.createCanvas(p.windowWidth, p.windowHeight)
    c.canvas.setAttribute('aria-hidden', 'true')            // 装饰性 canvas 对读屏器隐藏
    p.pixelDensity(Math.min(window.devicePixelRatio, 2))    // 上限 2，4K 屏不掉帧
    for (let i = 0; i < COUNT; i++) particles.push(new Particle())
  }
  p.draw = () => {
    p.background(8, 12, 20, 0.18)                            // 半透明覆盖 => 拖尾
    for (const pt of particles) { pt.update(); pt.draw() }
  }
  p.windowResized = () => p.resizeCanvas(p.windowWidth, p.windowHeight)
  p.mousePressed = () => p.saveCanvas('poster', 'png')        // 点击存图
}
new p5(sketch, document.body)
</script>
```

## 核心 API 速查

| 类别 | API |
|---|---|
| 生命周期 | `preload` `setup` `draw` `windowResized` |
| 事件 | `mousePressed/mouseDragged/mouseWheel(e)` `keyPressed` `touchStarted`（移动端 `return false` 阻止滚动）|
| 画布 | `createCanvas(w,h[,WEBGL])` `resizeCanvas` `pixelDensity(n)` `frameRate(n)` |
| 输入 | `mouseX/Y` `pmouseX/Y` `mouseIsPressed` `keyIsDown(code)` |
| 数学 | `random(a,b)` `randomSeed` `randomGaussian()` `noise(x[,y,t])` `noiseSeed` `noiseDetail(oct,fall)` `map` `constrain` `lerp` `dist` |
| 向量 | `createVector` `p5.Vector.random2D()` `p5.Vector.fromAngle(a)` `.add/.sub/.mult/.limit/.setMag/.heading/.lerp` |
| 变换 | `push/pop` `translate` `rotate` `scale`（成对出现，漏 `pop()` 是常见 bug）|
| 样式 | `fill/noFill` `stroke/noStroke` `strokeWeight` `colorMode(HSB,…)` `blendMode(ADD)` |
| 图形 | `circle/rect(+rectMode)/line/arc` `beginShape/curveVertex/endShape` |
| 图层 | `createGraphics(w,h)` `loadImage` `loadFont`（离屏图层/遮罩，别每帧 new）|
| WEBGL | `box/sphere/torusKnot/plane` `orbitControl()` `ambientLight/directionalLight/pointLight` `specularMaterial` `shader()` |
| 导出 | `saveCanvas(name,'png')` `saveGif(name, frames)` |

## 高频配方

1. **鼠标交互粒子**（见模板，斥力/引力/吸引回落三选一）。
2. **柏林噪声流场**：`noise(x*0.003 + t, y*0.003)*TWO_PI*2` → `p5.Vector.fromAngle(a)` 驱动，最耐看背景之一。
3. **Perlin 山脉**：`noise` 起伏 + `beginShape` 顶点 + 多层不同速率叠加做视差。
4. **Lissajous 图案生成器**：参数方程驱动曲线，`seed` 做可复现「每日一图」。
5. **WEBGL 点阵星云** + `orbitControl()` 做可旋转 3D 主视觉。

## 铁律

- 粒子数按面积自适应 `constrain(面积/9000, 60, 420)`，别写死 1000。
- `pixelDensity` 上限 2；拖尾用半透明 `background()`，别每帧新建 `createGraphics`（内存泄漏）。
- 粒子必须回收（越界回绕或对象池），禁止无限 `push`。
- 装饰性 canvas 加 `aria-hidden` 并提供真实文字替代；交互型 sketch 留键盘替代路径。
- 尊重 `prefers-reduced-motion`：降级为静态帧（`noLoop()`）或大幅降运动。
- 页面隐藏时 `noLoop()`，回来 `loop()`，省电。
- 不要用 p5 做 UI 交互主逻辑（按钮/表单），它是画布库。
